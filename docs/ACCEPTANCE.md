# Acceptance checklist (before we leave for the office)

- [ ] A full run-through from reset takes under 25 minutes without help
- [ ] A report submitted in the reporter appears on the dashboard in under 3 seconds (two windows on the same laptop)
- [ ] The compliance figure starts at 93.4% and climbs when exceptions are cleared
- [ ] Everything works with the network switched off (`npm run build && npm run preview`, or `python3 -m http.server -d dist`)
- [ ] Reset returns the app to the starting state
- [ ] Every screen shows the illustrative-data banner
- [ ] No real insurer names, people or numbers appear anywhere
- [ ] Typecheck, unit tests and build pass
